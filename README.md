Using the NYC 311 Service Requests dataset, in which are actual city service requests, with fields for the responsible agency, problem category, location, and creation and closure dates. Sourced from [NYC Open Data](https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2020-to-Present/erm2-nwe9/about_data?utm_source=chatgpt.com).

This project is to simulate the preparation for an operations review, focusing on sanitation requests created in Manhattan during January 2025. The driving questsions are 1) what drove demand and 2) where we should investigate delays.
