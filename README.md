Using the NYC 311 Service Requests dataset, in which are actual city service requests, with fields for the responsible agency, problem category, location, and creation and closure dates. Sourced from [NYC Open Data](https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2020-to-Present/erm2-nwe9/about_data).

This project is to simulate the preparation for an operations review, focusing on sanitation requests created in Manhattan during January 2025. The driving questions are as follows:
1. What are the five most common problem categories? Show their request counts and percentages of all requests in your extract.
2. Which of those five categories takes longest to close? Compare median elapsed hours from creation to closure, using records with valid closure dates. Show how many requests support each median.
3. What should be investigated first? Recommend one category, using both its volume and closure time. Explain what additional information needed before recommending an operational change.
